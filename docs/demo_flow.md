# SmartFactoryV2 데모 흐름

## 목표

운영 관리자가 AI 추천 생산순서를 기준선으로 확인하고, 직접 순서를 바꿨을 때 전환 비용과 리스크가 어떻게 달라지는지 확인한 뒤 최종안을 저장하는 흐름을 시연합니다.

## 시나리오

1. 백엔드 seed 데이터를 생성합니다.
2. 백엔드 서버를 실행하고 `/health`가 OK인지 확인합니다.
3. Decision 화면에 진입합니다.
4. 화면은 `demo-plan-001` 생산계획을 불러옵니다.
5. `POST /optimize` 결과로 추천 순서를 표시합니다.
6. 사용자가 순서를 조정합니다.
7. `POST /predict`가 추천안 대비 현재안 비용과 warning을 반환합니다.
8. `POST /explain` 버튼으로 template 기반 한국어 설명을 확인합니다.
9. 최종 확정 버튼으로 `POST /decisions`를 호출합니다.
10. Dashboard 화면에서 `GET /dashboard` 결과가 저장 decision을 반영하는지 확인합니다.

## 시연 포인트

- 검정 -> 흰색 전환은 high risk warning으로 감지됩니다.
- metallic -> non-metallic 전환은 중/고위험 warning으로 표시됩니다.
- 같은 색상군을 연속 배치하면 비용과 리스크가 낮아집니다.
- 확정 저장은 프론트엔드 계산값이 아니라 서버 재계산 결과를 기준으로 저장됩니다.

## 제외 범위

- 로그인과 권한
- 실시간 MES/ERP 연동
- 다중 생산 라인
- 납기/시간창 제약
- 실제 LLM 호출
